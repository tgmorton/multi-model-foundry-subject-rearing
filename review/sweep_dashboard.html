Europarl Annotation Pipeline

How we created training data from parallel EN-IT Europarl proceedings. The pipeline extracts English subject pronouns, aligns them to Italian finite verbs, and identifies null-subject positions.

English Processing spaCy en_core_web_trf
  • Parse Europarl EN text
  • Extract subject pronouns: I, we, he, she, they, you
  • Filter expletives, relatives, all "it"
  • Map to candidate labels (I → PRO.1sg, we → PRO.1pl, …)
Italian Processing spaCy it_core_news_lg
  • Parse Europarl IT text
  • Detect finite verbs (VerbForm=Fin)
  • Check subject status: overt / null / clausal / expletive
  • Extract morphology: Person, Number

Sweep Results

All 26 completed runs sorted by Detection F1. Feature accuracy is near-perfect across all configurations — the entire performance gap lies in detection, not classification.

Key Finding

Alpha = 0.0 dominates. Uniform class weights (no reweighting) consistently outperform weighted variants. Higher alpha values boost recall at the cost of precision, but the net DetF1 is always lower. The best run achieves DetF1 = 0.768 with Feature Accuracy = 1.000, meaning every correctly detected pronoun is assigned the right person/number label.

Next Steps

Five directions to improve detection performance beyond the current DetF1 = 0.768 ceiling.

01
Scale the Data Further
We've used 500K of the available 1.9M Europarl pairs. DetF1 gains are clear from 100K → 300K → 500K and the curve hasn't plateaued. Scaling to the full corpus should yield an estimated ~170K packed passages.
02
Make the Classifier Binary
Feature accuracy is already 99.9–100%, so the 7-class head wastes gradient signal on a solved problem. A binary classifier (NONE vs PRO) gives cleaner gradients; person/number can be resolved post-hoc from Italian verb morphology.
Current: 7-class
Softmax(7)
NONE 1sg 1pl 2sg 2pl 3sg 3pl
Proposed: 2-class + rules
Sigmoid(1)
NONE PRO → spaCy morph
03
Threshold Tuning
Currently using argmax with no threshold. With a binary head, we can sweep the P(PRO) decision threshold to optimize the precision–recall trade-off for the target use case.
04
Longer Context Window
Pro-drop is discourse-sensitive: the antecedent for a null subject may appear several sentences back. Increasing max_seq_length from 256 to 512 tokens doubles the context window from ~180 to ~360 words.
CURRENT: 256 tokens ≈ 180 words
PROPOSED: 512 tokens ≈ 360 words
Trade-off: 2× memory, ~1.5× training time. May need gradient accumulation or smaller batch size.
05
Test Different Base Models
mDeBERTa-v3-base is a strong multilingual choice, but Italian-specific or larger models may improve encoding quality for pro-drop detection.
